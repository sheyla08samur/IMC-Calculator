# ✨ Calculadora de IMC 🧮

Una aplicación web sencilla para calcular el **Índice de Masa Corporal (IMC)** a partir de los datos ingresados por el usuario. Usando HTML, CSS, Vite y JavaScript. 🧑‍💻🌐

## 🚀 Características

- Ingreso de nombre, edad, peso y estatura
- Cálculo automático del IMC al presionar un botón
- Mensaje personalizado según el resultado del IMC
- Imagen ilustrativa de acuerdo al estado de salud 🖼️
- Opción para reiniciar los valores y hacer un nuevo cálculo 🔄

## 🛠️ Tecnologías usadas

- HTML5
- JavaScript Vanilla
- Vite como bundler (⚡️ rápido y ligero)
